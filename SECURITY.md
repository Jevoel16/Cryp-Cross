# Security policy

## Supported versions

Only the latest release on `main` gets security fixes. The live site always runs `main`.

## Reporting a vulnerability

Please report it privately, not in a public issue. Use [Report a vulnerability](https://github.com/Jevoel16/Cryp-Cross/security/advisories/new) on the Security tab.

Include the page or endpoint, the steps to reproduce it and what an attacker could do with it. I'll reply within 7 days and say when a fix is expected.

Out of scope: the shared demo account (its password is public on purpose and it can't change anything) and rate limits on a local dev server.

What the app already does is listed in [docs/security.md](docs/security.md).
