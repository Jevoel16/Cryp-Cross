# Code of conduct

This project follows the [Contributor Covenant 2.1](https://www.contributor-covenant.org/version/2/1/code_of_conduct/).

In short: be kind, assume good intent and keep feedback about the work, not the person. Harassment, insults and personal attacks aren't accepted in issues, pull requests or anywhere else the project lives.

To report a problem, contact the maintainer through [GitHub](https://github.com/Jevoel16). Reports are kept private.
